# Comparative Macroeconomic and Demographic Analysis of Five European Nations
# By Xavier Malin, November 3rd 2026
## Project Purpose
This project implements an automated web scraping and data analysis pipeline targeting Wikipedia pages for five major European countries: **France, Spain, Germany, Poland, and Italy**. The objective is to extract core demographic, geographic, and economic indicators, clean the raw text into structured Pandas DataFrames, and conduct multi-variable analysis answering specific analytical questions.

## Data Source
- **Website:** [Wikipedia](https://www.wikipedia.org/)
- **Target Pages:**
  - [France](https://en.wikipedia.org/wiki/France)
  - [Spain](https://en.wikipedia.org/wiki/Spain)
  - [Germany](https://en.wikipedia.org/wiki/Germany)
  - [Poland](https://en.wikipedia.org/wiki/Poland)
  - [Italy](https://en.wikipedia.org/wiki/Italy)
